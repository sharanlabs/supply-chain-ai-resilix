## Raw verdict (Codex, verbatim)

**High**
1. §6/C13, §10 — Circular meta-control. Process adherence is checked by `acceptance-gate` + `guidelines-monitor`, which are themselves part of the process being certified. Fix: a separate evidence-audit artifact verifying every gate input/output, raw transcript, command log, checklist item before C13 passes.
2. §6/C3, §10 — Success criteria not mapped to controls. `Success_Criteria.md` has hard gates (live mode, auth, atomic approval, idempotency, packet versioning, CSV guards, cost ledger, hallucination, demo honesty, six scenarios); §6 collapses them into generic `npm run verify`. Fix: criterion→control matrix; each row names the exact test/eval/log artifact and fails if unmapped/skipped.
3. §6/C10 — Security too narrow. Only injection/output-handling; OWASP LLM Top-10 2025 has all ten (LLM02 sensitive disclosure, LLM03 supply chain, LLM04 poisoning, LLM06 excessive agency, LLM07 prompt leakage, LLM08 vector, LLM09 misinformation, LLM10 unbounded consumption). Fix: LLM01–10 threat-control-test matrix with N/A justifications.
4. §2/§6 — Current agentic canon gap. Omits OWASP Top-10 for Agentic Applications 2026 + AIUC crosswalk (goal hijack, tool misuse, identity/privilege, memory poisoning, inter-agent, cascading failures, runtime containment, monitoring, attestation, schema controls). Fix: add 2026 Agentic coverage with tests.
5. §6/C2 — Cross-model gate bypassable. Evidence is `/tmp/*` + thread ID + maker-recorded verdict; maker controls the prompt, may summarize selectively, `/tmp` not durable. Fix: commit exact prompt, artifact hash, model identity, full raw transcript, verdict, closure under `docs/claude/gates/<artifact>/`.
6. §4/§5/§6/C2 — "Different vendor" conditional, not structural. If Codex authors an artifact it can't judge it; read-only prevents mutation, not bias. Fix: record maker/judge model + vendor/family + role; prohibit same-family/same-session self-review.
7. §6/C7/C8/C11/C14 — Self-report controls as assurance. Legibility/cost/recency/no-thrashing are "self." Fix: downgrade to operator habits or replace with automated evidence (usage ledger, source manifest, state-diff script, lintable narration).
8. §2/§6 — WCAG 2.2 AA no enforcing control. Fix: a11y gate — axe/Playwright, keyboard-only, focus order, 320px reflow, target size, status messages, evidence per route/process.
9. §2/§6/C3 — Eval canon unenforced. "≥100 labeled," "judge ≥ system," golden tasks, regression-as-BLOCK, ADK taxonomy not bound to an artifact. Fix: eval spec — dataset manifest, label provenance, judge calibration report, thresholds, regression IDs, per-run results.
10. §10 — DoD satisfiable by checkboxes. Fix: DoD references an evidence manifest; every item needs file path, command, timestamp, actor, verdict, artifact hash.

**Medium**
11. §2 — Missing enterprise web-app security canon (OWASP ASVS, OWASP Web Top-10, NIST SSDF) despite Next.js APIs/uploads/auth/mutations. Fix: ASVS/SSDF controls.
12. §2 — AI risk governance missing (NIST AI RMF + GenAI Profile). Fix: AI risk register mapped to govern/map/measure/manage.
13. §6/C4 — Multi-source rewards count not quality. Fix: source class, official-doc priority, quote/extract, accessed date, version, claim mapping, conflict-resolution.
14. §6/C5 — Failure-knowledge prose-first. Fix: each failure → mitigation owner, deterministic test/eval, negative case, residual-risk decision.
15. §6/C12 — Tech-stack vetting misses dependency/supply-chain. Fix: lockfile diff, `npm audit`/SCA, license allowlist, package provenance, SBOM.
16. §6/C9 — Do-no-harm incomplete (overwrite, stale HEAD, generated churn). Fix: pre-edit `git status`, scoped diff, touched-file list, snapshot path, post-edit diff.
17. §2/§6 — Observability/SLOs named, not controlled. Fix: SLO definitions, log-schema tests, audit-log assertions, health checks, alert dry runs, rollback.

**Low**
18. §5/C6/§8 — Anti-slop mixed with assurance. Fix: keep editorial review separate from correctness/security; block only on clarity issues that hide risk.
19. §8 — Commit/formatting rules overclaimed. Fix: move hygiene out of the assurance matrix unless enforced by a lint/script tied to a real failure mode.
20. §11 — Self-improvement loop lacks measurement. Fix: per-process metrics — repeated defect rate, gate false-negative count, escaped defects, cycle time, cost, rollback criteria.
