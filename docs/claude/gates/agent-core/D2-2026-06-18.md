## What changed
- **Exposure model** (`lib/agents/actionops/atlas.ts`): `exposureScore =
  RISK_TIER_BASE[riskTier] + clamp(standardLeadTimeDays - 30, 0, 30)` (base CRITICAL 55 /
  HIGH 40 / MEDIUM 25 / LOW 12). **Integer by construction** (no `Math.round`) to avoid an
  IEEE-754 round-half coin-flip vs the hand-computed fixtures (advisor-caught). Ranked
  desc, stable id tiebreak. `backupSupplierId` is always-null in the seed → documented as
  a future factor, not used.
- **Sentinel-handoff firewall (the deliberate-misclassification rejection):** a
  `CHOKEPOINT_AFFECTED_COUNTRIES` map derives the THREAT's geographic scope from the
  handed-in threatCard (canonicalized trim+lowercase). Atlas FAILS CLOSED — zero exposures
  + a stated dataGap + `agentRun.validationStatus="FAIL"` — when (a) a matched supplier is
  outside a known scope (misclassification), or (b) a chokepoint is claimed but unmapped
  (cannot validate). Non-chokepoint threats pass through. The unit assert corrupts only
  the handed-in threatCard (Hormuz→Malacca) so the corruption changes the correct answer
  (non-vacuous — NOT the `f(x)===f(x)` trap an earlier schema-validation version was).
- **Gatekeeper fail-closed** (`gatekeeper.ts` + `index.ts`): `runActionOpsGatekeeper` now
  takes `agentRuns` and BLOCKS (`approvedForHumanReview=false`) on any agent
  `validationStatus==="FAIL"`. Without this the firewall failed OPEN (the FAIL flag was
  cosmetic; a rejected packet stayed approvable). This is the firewall's real teeth.
- **Sector firewall:** a supplier sector outside the closed `SectorSchema` → `OTHER_UNMAPPED`.
- **Zero-exposure control:** a genuine no-match → empty + "no direct exposure" dataGap.
- **Tests** (`evals/actionops-atlas.test.ts`): 9 Gulf scores HAND-DERIVED + pinned by stable
  seed name; rank; misclassification→FAIL→gatekeeper BLOCKED (end-to-end); whitespace/casing
  robustness; unmapped→fail-closed; sector firewall; zero-exposure; the empty-exposure
  cascade through `runActionOpsAgents` (no throw; honest zero stays PASS, distinct from a
  FAIL rejection). `demo-packet.ts` carries a packet-VISIBLE audit line disclosing its
  scores are illustrative (fallback), not live-model output.
