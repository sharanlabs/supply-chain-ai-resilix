The home render passes `live:false` (proven by the e2e run with `ENABLE_LIVE_AI` unset); the route's `live` param defaults FALSE; `verify:full` is structurally incapable of billing.

**Preflight wired.** `assertConfiguredModelAvailable` (REST ListModels) runs at the live entry, self-guarded by the same `live && liveAiEnabled()` predicate; fails loud if the configured model isn't on the key.

**All 6 production scenarios built (was 1).** Only Hormuz existed in production (`SCENARIOS`); the other 5 were golden test fixtures only. Added tariff / Red Sea / hurricane / bankruptcy / zero-exposure / off-taxonomy as real production scenarios, each with scenario-keyed replay signals so the live Sentinel classifies the scenario's own disruption (the old global signal board was generic + earthquake-dominated → misclassification). Closes the "scenario coverage 6 of 6" criterion. Deterministic coverage proven by `evals/actionops-scenario-coverage.test.ts` (12 tests).
